# VisionFive 2: the appendices to notes/visionfive2.md

[`notes/visionfive2.md`](../visionfive2.md) is the page to read: radon's board facts, the bench
runbook and every bench stop in summary. The files here hold the evidence, one topic or one bench
session each, and the parent links each one where it summarizes it.

  2026-08-21.
