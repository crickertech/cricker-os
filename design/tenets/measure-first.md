# Measure first, then decide

*Appendix to [`AGENTS.md`](../../AGENTS.md), which carries the rule in one sentence. This file
carries the ruling in calef's words, why it earns a heading of its own, the case that produced it,
the counterweight, how it sits beside its neighbours, and the saying's missing author. Written
2026-09-24 (UTC) as its own tenet on calef's ruling (#1182), and folded into the rule-and-appendix
shape after #1189 split `AGENTS.md`. Name: ratified 2026-09-24 (calef, approving #1182).*

calef, 2026-09-24: *"I think a more general standard is that we want to measure first and then
decide. When we decide it might be a different remediation depending upon context and sometimes we
need time to inform that context."*

The value under it, *make decisions with data*, `AGENTS.md` already states four times (numbers
rather than adjectives, benchmarks first-class, question 5, a proposal that shows rather than
argues), and a fifth copy would make every one cheaper. All four assume the data exists. This is
the case where it does not. **Getting the data is the action**, not a prelude to one; choosing the
remediation before the measurement is the error however obvious that remediation looks;
remediation is separate work decided with the data in hand, it varies with context, and
sometimes context takes time.

**Agreeing with the value does not prevent the error, which is why this earns a heading.** Pull
request #1173 (a measure per mechanism, so each layer shows what it catches) asked what a zero-catch
count should mean. The lane wanted the consequence fixed in advance, or it would be decided while
looking at a check somebody was attached to; the maintainer agreed and proposed fixing each window
up front. Both wanted to decide with data and both were deciding before any count existed. calef
overruled both: a threshold chosen in ignorance is no better than one chosen under attachment,
because nobody can say what "too long with zero catches" means before seeing nine layers' spread.

The counterweight is the honest half. *Let us measure first* is an available way to avoid
deciding, the proposal-shaped procrastination `AGENTS.md` names in its section on forks. Name the
question the measurement will answer, the data, and the reader; with no question it is that
procrastination in a lab coat.

Three neighbours sound adjacent, and with this one they are a single rule at three states of
knowledge, which has to be said or the file reads as disagreeing with itself:

- *We are all owners*: the fix is known, cheap and reversible, so make it rather than record it.
- This tenet: the problem is not understood, so measure it.
- *Move fast on what can be undone*: it is understood, and expensive or irreversible, so write
  it up and stop. *Nobody remembers* sits under all three, and none of the three permits doing
  nothing.

The saying usually reached for here has no author. *"In God we trust, all others must bring
data"* is universally hung on W. Edwards Deming and traces to no source of his: Quote Investigator
finds it already a cliche in 1978, and Oxford Reference lists it as a misattribution. Use it
unattributed or not at all.
